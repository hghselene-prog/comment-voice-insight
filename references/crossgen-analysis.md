# 跨代消费者声音对比方法论

> 来源：从 MateBook Fold 一代/二代/Fold S 三代对比实战中沉淀。当你要对比「同一产品线不同代际」或「新品 vs 老品」的用户声音时，用这套方法。

## 一、核心问题：绝对声量不可直接横比

不同代际的视频播放量、评论数往往差一个数量级（如一代头部视频 5000 赞，新品刚发布只有 600 赞）。直接比绝对声量会得出「一代比新品热十倍」这种**由样本量造成的假结论**。

**解法：组内归一化占比。**

```
某组某主题占比 = 该主题点赞声量 / 该组总点赞声量 × 100%
（每组内部加起来 = 100%）
```

这样比的是「结构」而非「规模」——回答的是「这一代用户**主要在吵什么**」，而不是「哪一代吵得凶」。

配套规则：
- 主题**可多命中**（一条评论可同时归入「价格」和「生态」），所以各主题占比之和 > 100%，这是预期行为。
- 同时保留「条数」用于定性描述，「点赞加权声量」用于排序——两者都能在报告里查到出处。
- 每组样本量、总声量必须显式标注，让读者自己判断可信度。

## 二、心态演进链：把三代串成一条故事线

光并列三代的主题占比是"数据罗列"，不是洞察。要提炼出**演进逻辑**。实战中总结出的通用框架：

| 阶段 | 典型用户心态 | 声量特征 | 代表信号 |
|---|---|---|---|
| 首代（开创期） | **猎奇崇拜** | 形态/创新主题主导，价格敏感度低 | "看见创新就是好事""富哥玩具" |
| 二代（成熟期） | **用后审视** | 便携/价格/生态上升，出现真实使用诉求 | "这个价格难接受""视频创作适配吗" |
| 新品（话题期） | **情绪两极** | 立场/对比主题冲高，场景质疑出现 | 友商对比、民族情绪、"你折它干什么" |

**一句话叙事模板**：「同一条产品线，一代被当展品欣赏，二代被当商品审视，新品被当话题争论——用户评价体系从『创不创新』切到『能不能用/值不值』」。

提炼三步：
1. 对每代找**第一主题**（归一化占比最高者）→ 定"主导情绪"标签。
2. 找**迁移最剧烈的主题**（如价格从 15% → 1.5%，游戏从 10% → 21%）→ 这是故事转折点。
3. 给转折一个**解释**：为什么变？（新品未发布→价格失声；离真实使用越远→越谈立场、越近→越谈参数。）

## 三、立场分层（可叠加在任一代上）

除了按主题，还可以按**评论立场**三分，做成立体交叉：

- **质疑派**：质疑产品力/价格/场景（"能玩 3A 吗""贵"）
- **情绪派**：立场表达/友商对比/民族情绪（不谈产品本身）
- **认同派**：认可创新/看好生态（"国产加油""形态领先"）

每派取 3-4 条高赞原话，带点赞数和原视频链接——这是说服力来源，也是溯源基础。

## 四、口径声明（必须写进报告）

1. **数据源**：B 站公开 API 匿名采集，未登录态每视频仅放少量热评 → 方向性洞察，非精确统计。
2. **跨源不混算**：若引入历史报告（如小红书/电商已购用户数据），数据源不同，**只做定性呼应，不混算数字**。
3. **权重定义**：声量 = 累计点赞；占比 = 组内点赞加权归一化；主题多命中。
4. **时间口径**：标注每组视频的发布日期区间，新品刚发布时评论以情绪和场景质疑为主，与使用口碑不完全可比。
5. **可溯源**：每条精选观点挂原视频 URL；正文关键数字带角标指向来源清单。

## 五、报告视觉规范（沿用用户既有偏好）

- 本分析线**默认浅色/白底报告**（深色可视化可读性差，用户明确偏好）。发布会风格另说。
- 图表内联 SVG（脚本计算坐标），深浅色可切换。
- 每个数字带角标，文末来源清单含：标题+机构+时间+口径+原始 URL。
- 未验证/预测数据灰色显示并标注；不同口径百分比不做横比。
